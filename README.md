# supafleet-demo

Landing page and interactive demo for [Supafleet](https://github.com/camc8/supafleet) — a self-hosted Supabase fleet manager.

Live at **[supafleet.camc8.com](https://supafleet.camc8.com)**

## What's here

- `/` — marketing landing page (features, server recommendations, setup command)
- `/demo` — interactive mock dashboard showing the Supafleet UI with fake instances, logs, and metrics

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- React Router (client-side SPA routing)
- Deployed on Vercel

## Local dev

```bash
npm install
npm run dev
```
